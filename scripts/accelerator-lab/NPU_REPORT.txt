RESULT
All12 requested cases completed successfully through the real release CLI and
shared Rust window/merge pipeline. The corrected QNN encoder is useful: about
1.95x faster than CPU on warm4.74s speech and3.38x faster on warm180s speech.
CPU remains quicker for a cold short utterance. GPU was slower than both.
These results supersede the earlier conclusion that CPU was fastest with the
then-working unoptimized accelerator graphs. They do not imply every NPU model
or workload benefits equally.

IMPLEMENTATION
Mac DenseLocalAttention algebra ported to ONNX, retaining ONNX padding masks.
11284 ->3099 nodes before further QNN rewrites. No retraining/changed weights.
Actual hardware tensor tracing isolated QNN GatherElements lowering corruption:
458752/524288 wrong values in an exactly representable integer reproducer.
Equivalent reshape/slice relative shift removes that operation; explicit Floor
before three length casts preserves nonnegative length truncation on QNN.
The native Rust APIv2 provider registration now uses QNNExecutionProvider,
selects an NPU device and disables CPU fallback for the encoder. Strict hardware
smoke passed; profile recorded33QNN encoder executions. Preprocessor and TDT
decoder remain on CPU. A lab-only fixed-window capability prevents oversize
long-file chunks. Production builds default to the unchanged CPU behavior.

NPU: ORT1.29 + QNN2.7/QAIRT2.51, HTP FP16, cached encoder context.
GPU: WinML1.28.3 DirectML dynamic FP16 flattened graph. New static shift graph
still produced empty text on DirectML and was rejected, not counted as speedup.
The releaseCLI checks for providers_shared.dll even though standalone WinML
does not ship/require it. The GPU test bundle includes installed1.28.2 auxiliary
providers_shared.dll to satisfy that presence gate; actualCLI tests succeeded.
CPU: installed approvedINT8 host fix ee2e86a279225439c7a1ebb3f45492c5a5285be4.
Staged calibration/QDQ export tooling has synthetic regression tests, but a full
quantized export was NOT completed. These NPU results are FP16, not INT8/QDQ.
