# Sagascript 1.2.0

## What changed

- Configure independent **push-to-talk and toggle shortcuts** for each language profile. Use either or both.
- Personal dictionary edits now have explicit **Save and Discard** actions, with protection against losing unsaved changes when navigating.
- **Finnish** is available with multilingual Whisper Base as the default local engine. FinnishNLP Tiny is an optional specialist engine; no accuracy improvement over Base is claimed.
- **Windows ARM64 (Snapdragon)** joins the stable release after manual testing on a physical machine. **Windows x64 (Intel/AMD)** remains beta.

Transcription runs locally on your computer. The new meeting workflow is deferred to the next release. Existing file transcription and speaker diarization remain available.

## Installation notes

- macOS: Apple silicon, macOS 13 or later. The release app is signed and notarized.
- Windows: installers are **unsigned** and may show a SmartScreen warning. Stable/beta describes acceptance status, not code signing.
- Windows checksum verification: compare `Get-FileHash .\Sagascript-Windows-<architecture>-Setup.exe -Algorithm SHA256` with the matching `SHA256SUMS-Windows-<architecture>` release attachment.
- When upgrading, verify the displayed version and try a short dictation with your configured shortcuts.
- Finnish has not been accepted by a native-speaking manual tester. Published model benchmarks do not establish accuracy for your microphone and dictation.

## Publication checklist — remove this section from published notes

- Rebuild 1.2.0 from the approved immutable release revision. Do not relabel the older 1.1.3 test installers.
- Verify final macOS signing/notarization, Windows architecture/build identity, and all checksums.
- Smoke-test the rebuilt artifacts: install/upgrade, permissions, retained profiles/models, Swedish/English dictation, both shortcut modes, auto-paste, file transcription with speaker diarization enabled, relaunch and CLI version.
- Attach Windows ARM64 to the stable draft; keep Windows x64 on an explicitly labelled beta prerelease.
- Publish only after exact-target approval. Deploy the website copy after v1.2.0 is public and download links are verified.
