# Sagascript identity

The Sagascript identity uses one custom, soft S silhouette everywhere.
`sagascript-mark.svg` is the canonical monochrome glyph;
`sagascript-app-icon.svg` places the same geometry on the app-icon field.

## Safety and recognition constraints

- Always show one S, never a pair or repeating pattern.
- Keep the rounded inward-facing terminals, continuous curves, broad bowls,
  and clear waist.
- Do not introduce straight diagonal segments, sharpen the glyph into a
  lightning bolt, or reconstruct it as a historical rune.
- At menu-bar sizes, use the monochrome mark as a macOS template image without
  a surrounding tile.
- Derive raster exports from these masters; do not redraw individual sizes.

The generated concept proofs are exploratory references only. They are not
production masters.
